# 揮手與思考：可復刻動作配方

配方 ID：`female_gestures_v1`，第 1 版。固定採用女性揮手 **V3.9** 與思考 **V3.6**；不是早期的通用 wave／think 預設。執行不需要 Spine、原作者電腦、舊工作區或重新生成圖片。

## 直接復刻

AI 先呼叫 `list_motion_recipes`、`get_motion_recipe`，再呼叫：

```json
{"recipe_id":"female_gestures_v1","project_id":"gesture-demo"}
```

以上是 `instantiate_motion_recipe` 的參數。工具會把內附角色、31 張共用 PNG、骨架、網格、兩段固定動作和手型參考圖複製到新專案，不覆蓋既有角色。安裝包含所有檔案；不需要下載參考影片才能重播。回傳 `render_requests`，逐項交给 `start_render` 的 `spec`，輪詢 `render_status` 到完成後再開始下一項。兩動作使用同一取景與角色版本。

`verify_motion_recipe` 檢查角色分件雜湊、骨架、槽位順序、網格與兩段時間軌。`apply_motion_recipe` 可用目前的 `expected_revision`、`actions:["wave","think"]` 與 `overwrite:true`，將調整過的動作恢復為固定配方，保存成新修訂。它會拒絕素材或骨架不符的角色，也會拒絕過期版本。

相同配方能重現內附角色的部件、手型、姿勢和時序。MotionForge 與 Spine 的光柵化不同，不承諾兩引擎的逐像素輸出相等。骨架名稱相同不代表其他角色可以直接使用相同角度；換角色須完成下述對位。配方檢查不自動核准新渲染的美術。

## 共用分件與手指改模規則

- 所有動作共用同一套頭、髮、臉、衣服、上臂、前臂和袖子；只替換手腕至指尖的獨立手型。不得為一段動作重生成整個人物或整條手臂。
- 臉底不混入頭髮或表情；手不能混入髮絲、袖口或臉。遮住的髮、手臂及關節重疊區要補齊，透明度遮罩不能代替補繪。
- 手型須匹配該角色的膚色、線條粗細、陰影、手掌大小、指長及左右手拇指方向。A、B 角色使用自己的素材，不把內附女性手貼到別人身上。
- 以**腕根中心、腕寬及手掌方向**對位，不以整張圖片中心或指尖對位。手指屈曲不能用全手縮放、剪切或單純旋轉冒充。
- 掌心翻轉使用多張手型逐步替換；手指維持五指的結構，不能突然多指、融合或把食指變成僵直指示棒。先看 `hand-reference.png`，再逐張看實際透明素材。
- 腕根深入袖內。圖層由後到前是**下袖／袖口下緣 → 手 → 獨立袖口上緣**。只用一整圈袖口蓋住手，會再次露出不合理的橢圓邊。
- 手腕骨是前臂的子骨。腕根網格跟隨前臂，掌部跟隨手腕；袖口上緣跟隨前臂，避免腕部擺動時把關節扯開。不要為了消除破口而把手腕鎖死。
- 內附垂手網格上方約 20% 跟隨前臂；翻掌附件的 UV `v <= 0.18` 跟隨前臂，其餘跟隨 `palm_turn`。這是本素材的對位，不是所有手圖通用的百分比。思考兩張手型綁在 `hand_left`，腕根靠袖內重疊維持接合。

提供給呼叫端圖像工具的手型要求：

> 依此角色的原手製作獨立透明手部附件，只包含腕根至指尖，延伸少量腕根供袖口遮擋。保持原角色膚色、畫風、線條、比例及左右手方向，不添加衣袖、頭髮、臉或背景。以同一腕根中心及腕寬對齊各姿勢。翻掌系列由自然垂手、半側手到掌心朝鏡頭；思考系列為食指鬆屈及較收攏的自然彎曲姿勢，其他指節柔和收起，不要伸直食指指向臉。

MotionForge 本身沒有生成模型。此要求供有圖像編輯能力的呼叫端使用；若無法生成或取得合格附件，應回報缺少素材，不能以不完整動作冒充復刻完成。

## 揮手 V3.9

主要參考：[使用者指定揮手影片](https://share.gemini.google/5BYlxNNFZ6Qn)。使用畫面右側手，與參考影片換手；名稱 right／left 在此配方指畫面側，不能直接推論解剖學左右側。

- 手掌抬到下巴至臉旁，避免舉過頭。肘部留在身體附近，以前臂繞肘左右揮動四次，上臂與肩膀稍微跟隨；手腕有約 0.06 秒延遲，不能僵直鎖在前臂上。
- 起落各約 0.4 秒，整段約 **3.6667 秒**，30 FPS 含末幀共 **111 格**。骨骼資料以 60 Hz 取樣，保持檔案原時值；不要把所有鍵強制吸到 30 FPS 整格。
- 揮動起點約 0.3433 秒，提前接入起手尾段。四個前臂峰值約 0.5167、1.25、2.0667、2.8333 秒。約 3.14 秒起，最後向外擺動直接帶入放下，不先回正再停住。
- 肩／上臂揮動延遲約 0.05 秒，手腕約 0.06 秒，胸口約 0.0933 秒，頭約 0.1333 秒。保留小幅跟隨，不能把所有部位完全同步。
- 此骨架抬臂基準約 6.2°，前臂約 145°並疊加約 11.5°衰減擺動，手腕約 19.8°並疊加約 13.5°延遲擺動。數字是相對 setup 的偏移，**只適用內附骨架**；完整曲線以 `character.json` 為準。

## 思考 V3.6

主要參考：[使用者指定思考影片](https://share.gemini.google/5ovDzjRH3eaf)，只取其**前四秒的動作內容**，成品重新編排為 **4.8 秒**，30 FPS 含末幀共 **145 格**。使用畫面左側手。

- 手慢慢靠近下巴／臉旁；食指自然彎曲，由鬆屈逐漸收攏，其他手指柔和收起。不是指向臉的伸直食指，也不是整隻手快速拍到臉旁。
- 抬手約 1.3 秒，停留思考，再用約 1.3 秒放下。前臂、腕、頭依序跟隨；頭輕斜，眉部微收，眼睛只做輕微表情變化。
- 包絡 `S(u)=u³(10−15u+6u²)`，u 限制在 0–1；`T(t,lag)=S((t−0.20−lag)/1.30) × [1−S((t−3.05−lag)/1.30)]`。前臂 lag=0.04、手腕=0.10、胸口=0.06、頭=0.18、眉眼=0.14 秒。
- 內附骨架相對 setup：上臂 −4.5°、前臂 161.5°、腕 13°、頭 −5.2°、胸口 −0.3°，各乘其包絡。手腕平移 −1.5、頭 −2、胸口 +2.8 原始像素；眉旋轉 ±7.5°、向下 0.8 像素；眼部 Y 縮放最多 10%。其他角色須重新對位，不能用這些像素值硬套。

| 0.50 | hand_think_loose | 抬手中鬆屈食指 |
| 1.12 | hand_think_closed | 臉旁較收攏的姿勢 |

兩張思考手圖為 1024×1536 透明附件，使用同一 0.113 比例、腕根對位而非指尖對位。沿主不透明輪廓建立 UV hull，排除生成圖的透明留白與零散暈邊；內附網格已完成此處理。原素材沒有被重畫。torso 向後移八個槽，維持左前臂、手與袖口上緣在前方。不得再使用舊 `hand_think_left` 的早期手型取代這兩張。

## 換成其他人物的動作要領

0.3.1 起，先完成[關節、膚色與遮擋的共用組裝流程](JOINT_ASSEMBLY.md)。使用 `register_joint_attachment` 量測腕根及校色、`bind_joint_strip` 綁定連續裸露肘部、`set_layer_constraints` 保護手／臉遮擋，並以 `required_polygons` 保護衣服。這些修正應保存於角色，共用至兩個動作，不要靠修改動作曲線掩蓋分件問題。

1. 用新角色自己的分件建立胸、肩、肘、腕、掌部骨架；核對骨骼朝向及旋轉正負。定位腕根、肘心、袖口上下緣，以及下巴／臉旁目標。
2. 按上述手型要求製作該角色的垂手、六段翻掌、兩段屈指素材。腕根與袖口對齊後再編動作；手掌尺寸在換圖時不能跳動。
3. 先以角色實際肢長校準休息、臉旁及向外揮動三個姿勢，再沿配方時序插值。保持肘主導、肩腕延遲及四次揮動；不能靠伸長前臂去湊下巴位置。
4. 改用該角色的槽名稱與順序；不能照抄 torso 的 −4／−8 offset。先驗證袖下緣被手蓋住、袖上緣蓋住腕根，再檢查轉腕極限。
5. 鎖定原圖保真時，先完成附件、骨架與取景；本配方有刻意的腕／胸／頭小幅位移與局部眼／掌部縮放。`lock_identity` 須明確列出必要例外，不能默默關閉既有鎖或扭曲人物以通過檢查。
6. 使用 `get_motion_recipe(include_animation_data=true)` 取得參考骨架、附件與時間軌，改為新角色的名字、角度、比例和層序後，才用 `set_animation` 寫入。`apply_motion_recipe` 的嚴格復刻檢查不會把未校準的新角色當作相容。

## 每次產出都要檢查

- 正常速度、0.25 倍速及所有逐格畫面；放大腕袖、肘肩、手指、下巴接近區域及五官。記錄實際看過的圖與雜湊。
- 揮手：0.40–0.60 秒、3.14–3.44 秒不能再出現接點停留；自然左右反轉的瞬間減速不等於卡頓。原尺寸腕部速度只作診斷，新角色須依比例比較。
- 思考：確認 0.50、1.12、3.49、4.06 秒前後各格；指型逐漸收攏、掌寬一致，手指不穿臉，起落保持慢速。
- 腕根、袖口及肘部不能有新裂縫、過度拉伸、翻面或非人類折彎；肩、上臂、前臂與腕的跟隨須可辨認。
- 共用固定取景，PNG 含末幀供檢查，播放循環排除重複末幀；完整檢查前只能匯出標示草稿的包。

已知限制：內附角色保留既有後髮接線，轉掌的離散附件切換在慢放仍可辨認。這是目前版本的可追溯復刻，不代表最終美術已獲使用者驗收。未內附第三方參考影片或遊戲素材；來源連結與觀察記錄保留在 manifest。
