# 我的動作需求

- **角色素材**：附件名稱或工作區路徑；完整角色圖／已拆好的透明 PNG。
- **動作名稱**：例如揮手、待機、點頭。
- **參考資料**：影片、GIF、連結或按順序編號的圖片。
- **參考時間段**：例如第 2～5 秒。
- **模仿重點**：角色自己的哪一側、動作幅度、次數、速度。
- **保留項目**：站姿、表情、衣服、身材比例、攝影範圍。
- **不要採用的部分**：例如鏡頭縮放、背景、原影片角色的外觀。
- **動畫總長**：例如約 4 秒。
- **收尾與循環**：放回原位／維持最後姿勢；是否循環。
- **輸出**：透明 WebP／APNG／PNG 序列／GIF／spritesheet；尺寸與 FPS。
- **素材權利**：是否為自己創作或取得使用授權；哪些素材不可隨成果分享。

請先確認能讀取我的參考，整理動作安排與缺少的素材，再產生草稿供我查看。不要把數值檢查通過當成美術驗收。
