# MotionForge 0.3.1 展示素材

README 頁首使用專案作者確認的同一版本：原圖、揮手與思考動作。

| 檔案 | 內容 |
| --- | --- |
| `original.png` | 角色原圖的 768 × 768 展示排版，與動畫使用一致的取景範圍。 |
| `wave.webp` | 約 3.67 秒的揮手動畫，30 FPS，透明背景。 |
| `think.webp` | 4.8 秒的思考動畫，30 FPS，透明背景。 |

角色與手部素材由本專案使用圖像生成工具製作，動畫由 MotionForge 0.3.1 渲染。原圖排版與兩個 WebP 直接使用作者核准的輸出，沒有為 README 另外重繪或變更動作。SHA-256 記錄於 [manifest.json](manifest.json)。

展示核准日期為 2026-10-10（Asia/Taipei）。這是作者對展示結果的確認，不會把引擎工作區尚未完成的逐格審查紀錄改成全部通過，也不代表任意自訂角色都能自動得到相同效果。

內附 `female_gestures_v1` 配方使用另一個測試角色，保存揮手 V3.9／思考 V3.6 的原始動作資料。重播配方與新角色的組裝方法見 [動作配方](../../docs/GESTURE_RECIPES.md) 及 [關節組裝](../../docs/JOINT_ASSEMBLY.md)。
